## Purpose

This glossary defines terms used consistently across MOQ Values Matter.

Each entry is an independent `.mdx` file — atomic, deep-linkable, and independently maintainable. Entries do not duplicate definitions that live authoritatively elsewhere; where a full Atlas entry or foundation page exists, the glossary entry points to it.

If a term appears here, it must be used with the meaning defined in its entry.

---

## Layer 1 — MOQ Foundation

These terms originate with Robert Pirsig's Metaphysics of Quality. They are not redefined by this project. The authoritative narrative context for all of them is the [Canonical MOQ Foundation](/fundamentals/canonical-moq-foundation/) page.

| Term | One-line summary |
|---|---|
| [Quality](/fundamentals/glossary/quality/) | The primary reality prior to subject-object division |
| [Dynamic Quality](/fundamentals/glossary/dynamic-quality/) | The pre-conceptual source of novelty and moral progress |
| [Static Patterns](/fundamentals/glossary/static-patterns/) | Stabilized forms of value that preserve what has worked |
| [Physical Level](/fundamentals/glossary/physical-level/) | Inorganic patterns — matter, energy, physical laws |
| [Biological Level](/fundamentals/glossary/biological-level/) | Life processes — survival, instinct, pain, bonding |
| [Social Level](/fundamentals/glossary/social-level/) | Coordination patterns — customs, institutions, loyalty, power |
| [Intellectual Level](/fundamentals/glossary/intellectual-level/) | Reasoning patterns — ideas, logic, science, error correction |

## Layer 2 — Project-Wide

These terms are defined by this project and apply across all sections — Atlas, Essays, Methods, and governance.

| Term | One-line summary |
|---|---|
| [Canon](/fundamentals/glossary/canon/) | Stabilized intellectual static patterns forming the authoritative knowledge base |
| [Meaning](/fundamentals/glossary/meaning/) | Felt coherence arising when value patterns align across levels — a diagnostic outcome, not a primary value |
| [Field-Relative Valuation](/fundamentals/glossary/field-relative-valuation/) | The same action can objectively produce different value effects in different fields — without implying relativism |
