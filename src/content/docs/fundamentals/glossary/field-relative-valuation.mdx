## Field-Relative Valuation

**Field-relative valuation** is the principle that the same action can objectively increase value in one value field while objectively destroying value in another — not because value is subjective, but because real physical, biological, and social conditions differ across fields.

Field-relative valuation:
- describes objective differences in value effects across contexts
- is grounded in real consequences, not interpretation or opinion
- does not imply that all valuations are equally valid
- is compatible with a non-relative value hierarchy

Field-relative valuation is **not**:
- moral relativism — it does not claim that all value judgments are equally correct
- subjectivism — value effects are real, not perceived
- a license to justify any action by appealing to local context
- equivalent to "it depends" as a general escape from accountability

In conventional thinking, the observation that the same action has different effects in different contexts is often used to argue that morality is relative — that there is no objective standard. Field-relative valuation accepts the observation but rejects the conclusion. The differences arise from real differences in conditions, not from the absence of objective value. A military unit operating under different conditions than a civilian institution genuinely faces different value trade-offs — but this does not mean that all choices within either field are equally good.

Within this project, field-relative valuation is a diagnostic tool for understanding why value effects differ across contexts without collapsing into relativism. It is paired with the non-relative value hierarchy — the principle that some values are objectively higher quality because they preserve more levels and reduce destructive propagation. Local success in a value field does not imply high Quality in the MOQ sense.
